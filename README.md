# Modular Word Processor

## [Live Demo](https://jeschrich.web.illinois.edu/mwp-demo)

This repo contains the source code for the Modular Word Processor -- a malleable software environment 
for writers. Writers using the MWP can combine, share, and create custom tools and extensions called 
"modules." Combining, sharing, and using modules requires no generative AI components; for creating new 
modules, the system uses generative AI to turn natural language instructions into working code without 
requiring any programming experience.

# Using the Module Builder

To build new modules, you need to add an API key for your preferred coding agent. In the top left corner, click on the project name, then find "Settings" at the bottom of the menu.  Provide a key, address, and model, and click "Save".

# Live Demo
You can try the Modular Word Processor on the web: [Live Demo](https://jeschrich.web.illinois.edu/mwp-demo)

Your documents are saved only in local storage on your browser, and the tool does not collect any data from you. 

# Install Instructions

To install, you'll need nodejs and npm.

1. Download or clone the repository
2. run 
```
$ npm install && npm run dev
```
