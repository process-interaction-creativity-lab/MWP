# QA: sentence-length-spectrum

About five minutes. Write several paragraphs: mostly sentences of about eight words, a few very short ones, a few long ones, and a heading.

1. Typical-length sentences are clear; short ones shade blue, long ones red; none is a mix. The heading is not tinted.
2. Add one 60-word sentence: it is strongly red but the rest don't turn blue. Remove it: colours settle back.
3. Open the legend from its toolbar control: a bar fading blue to clear to red, shortest, median and longest counts, shorter / typical / longer labels, and the sentence total. Close it from the legend and reopen it from the control.
4. Type and delete in a paragraph: tints and legend update live, the caret doesn't move, Undo changes only your typing. Make every sentence the same length: nothing is tinted. Empty the document: the legend shows zeros.
5. With the legend open, reload: it is still open in that pane. Open a second pane on a different document: it has its own legend state and numbers.
6. Check light and dark themes: text stays readable.
7. Put sentence-length on the same pane: both controls and legends work separately; turn each off and on in turn.
