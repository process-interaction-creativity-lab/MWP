# QA: word-processor

About five minutes. Use a few paragraphs and a second pane on the same document.

1. Place the module: the toolbar shows bold, italic, underline, two list buttons, a heading picker, a size picker, a font picker and a colour control, and the palette lists the matching actions. Click into the text: the controls enable.
2. Select a word, click Bold, press Mod-B: it toggles; the Bold button looks pressed only while the selection is bold, and clicking it never loses the selection. Repeat for italic and underline with shortcuts.
3. Choose Heading 2, then Mod-Alt-0: heading, then plain paragraph again; the heading picker shows the level under the caret as you move.
4. Make a bullet list from the button and by shortcut, then a numbered one: the button shows its on-state inside a list. Tab on the second item nests it, Shift-Tab lifts it; Tab on the first item does nothing. Outside a list, Tab twice, Shift-Tab three times: it indents, steps back and stops at none, focus never leaving the text.
5. Select text and change size, font and colour (drag the colour picker): the controls show current values elsewhere in the text. Undo once: the whole colour drag undoes in one step. Undo and redo the rest.
6. With a collapsed caret choose a colour and type: the new text uses it. Move the caret: the controls follow.
7. Click into the second pane: the toolbar follows it. Format there: the first pane shows the same text, and undo is per pane.
8. Turn the module off: toolbar and shortcuts go, formatting stays. On: everything returns. With another module offering Mod-B, pressing it bolds once with no error.
