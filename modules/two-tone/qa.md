# QA: two-tone

About five minutes. Use three paragraphs of plain text.

1. Turn the module on: two joined buttons, Green and Pink, with Green filled green and a word count with green and pink totals appear, and all existing text counts and shows as green.
2. In green mode, select a phrase and use the recolour key: it turns pink. Again: green. Select a range mixing both: all becomes pink. The word count follows.
3. Click Pink (it fills pink, Green empties): each green passage becomes a "···" marker, only pink text is readable. Arrow across a marker: the caret hops over it. Select across one: the ends never sit in hidden text.
4. In pink mode type a word: it is pink. Backspace into a hidden run: nothing is deleted. Select across pink and hidden green and press Delete: only pink goes. Back in green mode, the green text is all there.
5. In pink mode select across hidden green and pink, copy and paste into a plain place: only pink arrives. Cut a mixed selection: same rule as delete.
6. Paste bold text in each mode: it keeps bold and takes the mode's colour. In green mode type over a selected pink word: the replacement is green.
7. Undo and redo through steps 4 to 6: text returns with its colour, and switching mode is never an undo step. Open a second pane, put it in the other mode: each keeps its own mode, and typing in one never recolours the other's text.
8. Turn the module off: everything shows; on: the colours are still there. Check the mode keys don't clash with another module's (such as search highlighting).
9. Select a few words in green mode: the bubble shows a green and a pink circle; the pink one makes them pink in one undo step. Switch to pink mode, select pink text: only the green circle shows, and it hides the text as green.
